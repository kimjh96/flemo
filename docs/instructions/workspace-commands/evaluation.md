# Evaluation entrypoints

Run workspace commands from the repository root. For `eval:agents:validate`, `eval:agents:prepare`, `eval:agents:ladder`, `eval:agents:analyse`, `eval:agents:score`, and `eval:agents:selftest`, follow the [agent-guidance evaluation guide](../../../evals/flemo-agent-guidance/README.md), including its release-corpus, isolation, scoring, and analysis requirements.
