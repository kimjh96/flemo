# Korean docs

Write Korean pages from the meaning rather than following English sentence structure. Reorder, split, or merge sentences freely.

- Use 해요체 throughout. Avoid stacking short "~예요." sentences; join related ideas with "~하고", "~해서", or "~면".
- Use workplace vocabulary familiar to Korean frontend developers: 화면 전환, 뒤로 가기, 진행도, 고정 헤더, 상태. Avoid literal coinages: 비행, 시계, 지명, 착지, 넘겨받다.
- Keep code identifiers in backticks and never translate them.
- Use "트랜지션" for what is defined and registered: `createTransition`, a preset, a name passed to `transitionName`, Part 트랜지션, or Morph 트랜지션.
- Use "화면 전환" for screens visibly changing: 전환 중, 화면 전환이 끝나면. Never write "Part 전환" or "전환 이름".
