# flemo agent-guidance evaluation

Test whether declaration JSDoc, public documentation, and the portable flemo skill help unfamiliar agents build complex motion correctly on the first attempt. This does not test copying the repository playground.

1. Understand the [four arms](./README/arms.md).
2. [Freeze the release corpus](./README/release-corpus.md).
3. [Run and score](./README/run-and-score.md).
4. [Score a build, and prove the rubric separates](./README/scoring.md).

[protocol.json](./protocol.json) fixes the full sample, effect threshold, failure handling, stopping rule, networked external-validity arm, and visual sample. [tasks.json](./tasks.json) fixes the three scenario prompts.
